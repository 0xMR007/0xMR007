## English

### About

Cybersecurity student in my final year of a Bachelor's degree in Computer Science, focusing on operational security - both offensive (penetration testing) and defensive (SOC, detection engineering). I build hands-on labs and tools to practice what I learn, and I am looking for a 12-week+ internship in operational security starting March 2027.

- Obtained the **eJPTv2** certification in July 2025
- Currently preparing the **HTB CPTS** certification through the HTB Penetration Tester job-role path, targeting 2027
- Long-term goal: becoming a **red team specialist**, while staying comfortable on the defensive side

### Flagship project - Lab4PurpleSec

[**Lab4PurpleSec**](https://github.com/0xMR007/Lab4PurpleSec) - a complete, open-source Purple Team homelab (332+ stars, 41 forks) combining a vulnerable Active Directory environment (GOAD), a Docker-based web DMZ, pfSense + Suricata, and a Wazuh SIEM. It is provisioned with Vagrant and Ansible and documents realistic attack/detection scenarios (Kerberoasting, AS-REP Roasting, web exploitation) end to end.
